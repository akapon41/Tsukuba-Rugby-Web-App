# Blues 個人成績ダッシュボード（静的Webアプリ）

Excelスタッツシート（`Individual AT ...` / `Individual DF ...`）をブラウザで読み込み、選手個人の試合別推移を確認するためのダッシュボードです。

## できること

- 選手選択（初期画面）
- 試合ごとの個人成績グラフ（AT/DF）
- 目標値達成チェック（しきい値は画面で変更可）
- コメント機能（`localStorage` 保存）
- いいね機能（選手/コメントごと、`localStorage` 保存）

## 起動方法

`file://` で直接開くとサンプル読込（`fetch`）が失敗することがあるため、ローカルサーバーで開いてください。

```bash
cd "/Users/jun.sugawara/Desktop/Web App"
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## 使い方

1. `サンプル読込` を押す（`Blues_2025.xlsx` を利用）または `xlsxを選択` でファイルを読み込む
2. 選手を選択
3. `ダッシュボード表示` を押す
4. 目標値を調整して達成数を確認
5. コメント/いいねを追加

## 実装メモ

- `xlsx` と `chart.js` は CDN 読み込み
- サーバー不要（バックエンドなし）
- コメント/いいねは同じブラウザでのみ保持されます
- Excelの列構成は、現行の `Individual AT/DF` シートの行7ヘッダ・行8以降の選手行を前提に解析しています
